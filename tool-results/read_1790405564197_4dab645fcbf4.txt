    73→### Conventions (MANDATORY for all screens)
    74→1. `"use client"` at top. Export `export function <Name>Screen()`.
    75→2. `const { filters, go } = useApp();` + `const ready = useRefresh("<id>");`
    76→   — render `ScreenSkeleton`-style composition while `!ready`.
    77→3. Wrap content in `<div className="space-y-4 animate-in fade-in duration-300">`
    78→   with `ScreenHeader kicker="MODULE 0X // NAME" title=… description=…`.
    79→4. Use `Panel`, `Badge`, `ScoreBar`, `Delta`, `Legend`, `Sparkline`,
    80→   `KpiCard` — do NOT restyle from scratch. Charts: recharts +
    81→   `CHART` colors + `useChartTheme()` for grid/ticks + `ChartTooltip`.
    82→5. Numbers: `fmtCompact`/`fmtNet` etc. from `@/lib/fmt`; mono + `tnum`.
    83→6. All data via `@/lib/mock` getters with `useMemo(() => get…(filters), [filters])`.
    84→7. shadcn/ui from `@/components/ui/*` for buttons/tabs/dialog/sheet/table/etc.
    85→8. Recharts XAxis for time series: `dataKey="t" type="number"
    86→   domain={["dataMin","dataMax"]}` + tickFormatter via point.label
    87→   (see OverviewScreen for copy-paste pattern).
    88→9. NO blue/indigo accents. NO rounded-full pills (4–6px radius only).
    89→   NO gradients on UI chrome (chart area fills at low alpha are OK).
    90→10. Layout: `grid grid-cols-1 xl:grid-cols-12 gap-4` rows of Panels.
