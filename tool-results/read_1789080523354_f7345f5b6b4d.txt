    61→    61→### Conventions (MANDATORY for all screens)
    62→    62→1. `"use client"` at top. Export `export function <Name>Screen()`.
    63→    63→2. `const { filters, go } = useApp();` + `const ready = useRefresh("<id>");`
    64→    64→   — render `ScreenSkeleton`-style composition while `!ready`.
    65→    65→3. Wrap content in `<div className="space-y-4 animate-in fade-in duration-300">`
    66→    66→   with `ScreenHeader kicker="MODULE 0X // NAME" title=… description=…`.
    67→    67→4. Use `Panel`, `Badge`, `ScoreBar`, `Delta`, `Legend`, `Sparkline`,
    68→    68→   `KpiCard` — do NOT restyle from scratch. Charts: recharts +
    69→    69→   `CHART` colors + `useChartTheme()` for grid/ticks + `ChartTooltip`.
    70→    70→5. Numbers: `fmtCompact`/`fmtNet` etc. from `@/lib/fmt`; mono + `tnum`.
    71→    71→6. All data via `@/lib/mock` getters with `useMemo(() => get…(filters), [filters])`.
    72→    72→7. shadcn/ui from `@/components/ui/*` for buttons/tabs/dialog/sheet/table/etc.
    73→    73→8. Recharts XAxis for time series: `dataKey="t" type="number"
    74→    74→   domain={["dataMin","dataMax"]}` + tickFormatter via point.label
    75→    75→   (see OverviewScreen for copy-paste pattern).
    76→    76→9. NO blue/indigo accents. NO rounded-full pills (4–6px radius only).
    77→    77→   NO gradients on UI chrome (chart area fills at low alpha are OK).
    78→    78→10. Layout: `grid grid-cols-1 xl:grid-cols-12 gap-4` rows of Panels.
